# Final Project - Full Stack Application

Proyecto final del curso de desarrollo web.

## Tecnologías

### Frontend
- React
- React DOM
- Vite
- React Router DOM
- TypeScript

### Backend
- Node.js
- Express
- MongoDB + Mongoose
- JWT (jsonwebtoken)
- bcryptjs
- CORS
- express-rate-limit
- tsx

## Estructura del Proyecto

```
/
├── client/          # Frontend (React + Vite)
├── server/          # Backend (Node.js + Express)
└── package.json     # Scripts de gestión del proyecto
```

## Scripts

- `npm run dev` - Ejecuta cliente y servidor en modo desarrollo
- `npm run dev:client` - Ejecuta solo el cliente
- `npm run dev:server` - Ejecuta solo el servidor
- `npm run build:client` - Construye el cliente para producción
- `npm run build:server` - Construye el servidor para producción
