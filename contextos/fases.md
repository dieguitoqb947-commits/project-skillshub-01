Etapa 0: Planificación y preparación
Durante esta etapa, elaborarás tu plan de trabajo y configurarás el repositorio necesario. No se envía a revisión.

Etapa 1: Desarrollo del front end
Esta es la base de tu proyecto, y se divide en dos lecciones: en la Etapa 1.1 armas la estructura del proyecto y la maquetación, y en la Etapa 1.2 conectas la API third-party. El pull request se envía una sola vez, al terminar la Etapa 1.2. Una vez que entregues tu trabajo, el equipo revisor te dará su feedback para que apliques las correcciones necesarias. Al finalizar, tendrás una aplicación front end totalmente funcional.

⚠️ Si eliges no completar la parte del back end, informa a tu success manager para que te dé permiso para avanzar sin finalizar las partes opcionales.

(Opcional) Etapa 2: Back end y Autorización
Si elegiste el enfoque full stack, esta etapa también se divide en dos lecciones: en la Etapa 2.1 creas tu propia API, la base de datos y la lógica de autenticación, y en la Etapa 2.2 conectas esa API con tu aplicación de React. El pull request se envía al terminar la Etapa 2.2.
